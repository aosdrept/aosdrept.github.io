FOR THE AOSD TEAM

Publish an event or project

Complete one entry for both languages. The website automatically updates the homepage announcement and the activities archive.

Open the Pages CMS editor

How to publish

  1. Open “Evenimente și proiecte”. Choose “Add an entry” to create an activity, or open an existing entry to edit it.
  2. Complete the shared details. Choose the type and status, the announcement date and any confirmed event dates, deadlines and registration link. Enter times in Romanian local time.
  3. Complete Română and English. Add the title, summary and full description. For each photograph, provide a short accessibility description in both languages.
  4. Review and click “Save”. Enable “Publică pe site” when the content is ready. “Evidențiază pe prima pagină” selects a featured announcement. If several are selected, the one with the most recent announcement date appears.
  5. Check the result. Allow the automatic publication to finish, then check both language versions. If your changes do not appear, check publication status below.
Publication status

Before saving

Save only content approved for publication. Saved files and photographs are public on GitHub, including when “Publică pe site” is disabled. Do not upload signatures, private data, membership applications or internal records.

Choose “Încheiat” (Completed) only once the activity has been confirmed as held. Update both languages for cancellations or changes. “Publică pe site” can hide an activity without deleting the entry.

Access and help

The editor is an external service, separate from the public website. The association administrator manages access and can invite editors. If the website is missing from your account, ask the AOSD team for access.

If a check stops publication, the previously published website remains available. Correct the field identified in the error message and save again.
